# edem

## Продакшн

- Деплой: `make deploy` (или `make deploy-branch BRANCH=<name>`). Остальные команды — `make help`.
- **Правка `.env` на проде — только через `make env-set KEY=<имя> VALUE=<значение>`.**
  Команда меняет значение, если переменная есть, или добавляет её в конец, делает бэкап `.env.bak`,
  выполняет `config:clear` и перезапускает контейнер `app`. Руками по ssh `.env` не править.
  Значение с пробелами передавать в кавычках для `.env`: `VALUE='"my value"'`.
- Уровень логов в Telescope на проде задаётся `TELESCOPE_LOG_LEVEL` (сейчас `info`).
