# Оптовая витрина

Главная `/` показывает оптовый каталог. Старый `/opt` перенаправляет на главную с сохранением параметров. Карточки сортов и отправка заявок продолжают работать в `/opt/{slug}` и `/opt/order/submit`.

`EnsureWholesaleOnly` закрывает розничные страницы, корзину, регистрацию, розничный фид и оформление розничного заказа ответом 410. Сохранены контакты, юридические страницы, оптовые заявки, админка и вход, Livewire и платёжный webhook для ранее созданных заказов. Sitemap содержит только оптовую витрину и вспомогательные страницы. Общая навигация больше не содержит розничных ссылок.

Nginx запрещает весь `/storage/`, кроме `/storage/wholesales/`. Розничные файлы, записи товаров и заказы сохраняются. После изменения nginx нужно проверить конфигурацию и перечитать её. Если контейнер использует старый inode файла конфигурации после предыдущих развёртываний, пересоздать только nginx, чтобы обновить bind mount.

Перед переключением сохранены исходные конфигурация и файлы приложения на сервере в `/root/edem-wholesale-only-20261120T212121Z/`. В `.env` изменений нет. Чтобы вернуть розницу, потребуется вернуть код предыдущей версии и конфигурацию nginx, очистить кеши Laravel и обновить nginx; один откат маршрута главной не откроет изображения.

Проверены изолированным HTTP-тестом Laravel с SQLite в памяти: оптовая главная и карточка, редирект с параметрами, контакты и политика, sitemap без розницы, ответы 410 на розничные страницы, регистрацию и POST заказа, валидация пустой оптовой заявки без отправки уведомлений. PHPStan завершился без ошибок.
