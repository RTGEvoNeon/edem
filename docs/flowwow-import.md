# Импорт товаров Flowwow

Ветка: `codex/flowwow-import-2026-11-04`.

Рабочий процесс для помощника: получить ссылку на карточку цветов → скачать
фотографии и фактический состав → посмотреть фотографии → написать собственные
название и описание → указать нашу цену и категории → импортировать черновик.
Состав, размеры и особенности нельзя придумывать, если они не подтверждены
карточкой или фотографиями. Обещания продавца, отзывы и рекламный текст не переносим.

Генерация текстов происходит в диалоге с помощником, отдельный AI API не нужен.
Парсер сам не пишет описание: он готовит материалы и требует заполнить собственные
тексты перед импортом. Поддерживаются карточки `flowwow.com/flowers/<slug>/`.

## 1. Скачать материалы локально

Playwright установлен в devDependencies. После первого `npm ci` при необходимости:

```sh
npx playwright install chromium
npm run flowwow:fetch -- 'https://flowwow.com/flowers/buket-iz-roz-nezhniy-briz/' --output storage/app/private/imports/rose-example
```

Открывается обычное отдельное окно Chromium, которое закроется после скачивания.
Прямой HTTP и режим `--headless` могут получать HTTP 403. При блокировке скрипт
останавливается без создания товара. Авторизация и обход CAPTCHA не реализованы.
Сессия Яндекса не используется.

Результат: `manifest.json`, 1–12 фото JPEG/PNG/WebP до 10 МБ каждое и
`content.example.json`. Выбираются изображения, явно связанные с этой карточкой
в JSON-LD: рекомендации, отзывы и логотипы не импортируются. Дубликаты одного
фото в разных разрешениях исключаются. Готовая папка не перезаписывается;
при ошибке временные файлы удаляются.

## 2. Подготовить собственный контент

Посмотреть скачанные фото и создать `content.json`. Цена Flowwow в manifest —
только справочная; она не становится нашей ценой автоматически. `categories` —
ключи существующих категорий, например `roses`, `mono`, `mix`.

Пример собственных текстов для указанной выше тестовой карточки (не опубликован):

```json
{
  "name": "Букет из 15 роз «Розовый жемчуг»",
  "description": "Розовые и кремовые розы собраны в округлый букет со светлой упаковкой и розовой лентой. Декоративная нить с бусинами добавляет композиции мягкий жемчужный акцент. Пятнадцать роз в пастельных оттенках подойдут для поздравления с днём рождения или тёплого знака внимания.",
  "price": 3900,
  "categories": ["roses", "mono"],
  "composition": "15 роз, декоративная упаковка, лента и декор с бусинами.",
  "size": "По карточке источника: ширина 25 см, высота 40 см."
}
```

Цена в примере условная: перед импортом подтвердить цену магазина. По желанию
можно заполнить собственные `care_instructions` и `seo_text`.

## 3. Импортировать

```sh
php artisan products:import-flowwow storage/app/private/imports/rose-example --content=storage/app/private/imports/rose-example/content.json
```

Команда выводит ID и адрес редактирования в админке. По умолчанию товар недоступен
в публичной карточке, каталоге, sitemap и YML. После проверки включить доступность
в админке или явно добавить `--publish` при импорте проверенного товара.

Источник сохраняется в `products.source_url` с уникальным индексом. Повторная
ссылка не создаёт дубль и не перезаписывает ручные правки. Категории привязываются
к реальной связи `categories`, имена файлов формируются из нового названия.
При ошибке вложения созданные медиа удаляются, записи откатываются транзакцией.
Папка исходных материалов сохраняется для проверки или повторной попытки.

Для продакшна достаточно передать готовую папку и `content.json` в
`storage/app/private/imports/`, затем выполнить эту же artisan-команду в контейнере
`app` от `www-data`. Браузер на сервере не нужен. Сначала код с миграцией должен
быть выложен через `make deploy-branch BRANCH=codex/flowwow-import-2026-11-04`.
Материалы не следует размещать в public или коммитить в Git.

## Проверки

```sh
node --test tests/Unit/flowwow.test.mjs
vendor/bin/pest tests/Feature/FlowwowProductImportTest.php
```

PHP-тесты выполнять только с отдельной тестовой БД. Проверены фильтрация фотографий,
собственные тексты и цена, категории, черновик, защита от дублей, повреждённых
файлов и выхода за папку импорта, удаление медиа при ошибке и явная публикация.
